# ADR：架构决策记录

## 决策摘要

TeamTodo V1 使用 PostgreSQL 作为主数据库。

## 背景

任务、项目、用户、评论之间存在清晰关系，后续也可能需要按团队和状态做查询统计。

## 备选方案

| 方案 | 优点 | 缺点 |
| --- | --- | --- |
| PostgreSQL | 关系建模清晰，事务可靠，查询能力强 | 部署和维护成本略高 |
| SQLite | 简单轻量，适合原型 | 多用户和生产扩展能力有限 |

## 决策

采用 PostgreSQL。

## 原因

- 适合任务协作类产品的数据关系。
- 支持事务，降低状态更新和评论写入的不一致风险。
- 后续扩展统计报表更方便。

## 影响

- 正面影响：数据模型稳定，查询能力充足。
- 负面影响：本地开发需要配置数据库。
- 后续动作：提供本地初始化脚本和迁移命令。

## 状态

- 已接受
